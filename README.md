# 乘數拔河・雙人即時對決

郭怡雅神父紀念學校小二數學乘法鞏固。

遊戲：https://hcl-fcms.github.io/p2-multiplication-tug-of-war/

## 玩法

- 同一裝置左右雙人同時作答，兩邊當前題目必定不同，各自獨立換題，毋須輪流或等待。
- 答對立即向自己一邊拉一格、立即換題；達指定淨位移即勝出。雙方均每題一格，沒有連答加倍。
- 答錯停留原題，該錯誤選項停用，可立即再試，不影響對方。
- 任選 2–9 乘數表，可只選 2、3 或全選；保留快戰、標準、大戰及分組提示圖。
- 建議 iPad 橫向使用，支援同屏左右觸控，並非跨裝置連線對戰。

## 教學與私隱

乘式沿用「每份數量 × 份數」，2 個 3 寫成 3 × 2；不教授乘法交換性質。比賽期間保留簡短回饋，賽後各隊優先檢視錯題並解釋連加（WHY）、用積木砌出分組（HOW）、回答蘋果應用題（TRANSFER），由教師確認理解。速度及勝負不能代替學習證據。

不收集學生資料；本機只保存設定。
