# 乘數拔河・大力王

郭怡雅神父紀念學校・小二數學乘法鞏固遊戲（2N3 延伸）。卡通拔河對戰：答對一題拉繩一格，答錯被對手拉走，旗幟過白線就贏。

**試玩**：https://hcl-fcms.github.io/p2-multiplication-tug-of-war/

## 特色

- **乘數任揀**：2 至 9 乘數表自由點選 — 只揀 2 同 3、全選 2–9 都得；另有「全選」「只揀 2 同 3」「全部清除」快捷鍵。
- **戰況長度**：快戰（先拉 3 格）、標準（先拉 5 格）、大戰（先拉 8 格）。
- **分組提示圖**：答題前可開啟「份份分明」蘋果分組圖，支援需要嘅同學。
- **WHY 回饋**：每題答後解釋「5 個 8：8+8+8+8+8=40」；答錯會停留解釋，學生睇完先按「繼續」。
- **大力一拉**：連續答對 3 題一次拉兩格，鼓勵連貫思考。
- **卡通化**：小熊隊 vs 狐狸隊、彩帶勝利畫面、音效（可關）。

## 教學口徑（與課堂一致）

- 乘式一律 **每份數量 × 份數**：例如「2 個 3」寫成 3 × 2。
- 揀選某個乘數表 n，即練習「n 個 a」：題目為 a × n（a 為 1–10）。
- 本遊戲**不教授乘法交換性質**，不顯示「掉轉都得」，與小二 2N3 現階段教學範圍一致。

## Thinking Gate（教學設計防呆）

- **WHY**：每題回饋講解「n 個 a」的連加意義；建議教師抽問學生口頭解釋。
- **HOW**：學生親自心算及選擇答案；提示圖只作支援，不代答。
- **TRANSFER**：混合多個乘數表即是情境轉換；教師可要求學生自編一題「n 個 a」應用題。

## 私隱

純課堂鞏固用途：不收集任何學生資料，只在本機記住音效、提示圖及乘數設定。
